# 100人の町ドミノ（hinan-domino）

10×10 のマス目の町に住む100人のうち1人に、「率先避難者」（まっ先に逃げて姿を見せる）か「声をかける人」（となりに声をかける）をたのみ、避難をドミノのように町の100人全員へ届ける1日5問のパズル（防災シリーズ BS9）。町の人は「見て逃げる人」「声で逃げる人」「2人に声をかけられたら逃げる人」に分かれ、置く場所と役目の選び方で全員に届くかが変わる。正解したら、ア〜エのどの人にたのむと全員に届くかも選ぶ。資料の問題（釜石の避難3原則・内閣府のガイドライン）も出る。「町をつくって試す」で、自分で人と役目を置いて1手ずつ広がりを見られる。

遊ぶ: <https://satou-aaaaa.github.io/hinan-domino/>

- 核：釜石の避難3原則の3つ目「率先的避難者になる」。中学生が「津波がくるぞー！」と叫んで走り、その姿を見て近所のお年寄りも走った（内閣府 広報誌「ぼうさい」 <https://www.bousai.go.jp/kohou/kouhoubousai/h23/65/news_06.html> ）。
- 声を掛け合う避難・呼びかけは、内閣府「避難情報に関するガイドライン」 <https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/pdf/hinan_guideline_r8_1.pdf> と「住民の適切な避難行動の促進に向けた好事例集」 <https://www.bousai.go.jp/oukyu/hinankankoku/pdf/jumin_hinan.pdf> から取りました。出典はゲームの「このゲームについて」にあります。
- マス目の伝わり方は、遊びのための単純な決まりです（見て逃げる人は、となりに逃げた人がいれば逃げる・声で逃げる人は、となりから声をかけられれば逃げる・2人で逃げる人は、となりの2人以上から声をかけられれば逃げる・率先避難者は姿だけ、声をかける人は声だけで知らせ、逃げた町の人は姿も見え声もかける）。人の行動を測ったものではなく、本物の避難の速さや広がり方ではありません。問題の町は練習のための例で、実在の町ではありません。数字は資料にある「600人」だけを使い、避難した人の割合は出していません。
- 問題は、作るときに200通りの置き方を全部ためし、全員に届く置き方がある町だけを出します（やさしい60〜150通り・ふつう8〜45通り（町を横切る2の並びの町だけ5〜45通り）・むずかしい1〜6通り）。
